## Executive Summary

This user research report synthesizes findings from market research, industry best practices, and project brainstorming to identify the specific analytics needs of three key user segments: **Players**, **Judges**, and **Clubs** in the Mafia card game community.

### Key Findings

1. **Players** prioritize performance tracking, historical trends, and improvement insights
2. **Judges** need tournament management, earnings tracking, and performance metrics (KILLER FEATURE)
3. **Clubs** require member analytics, team performance, and engagement tracking
4. **Willingness to Pay:** Highest for judge-specific features, moderate for advanced player analytics, variable for club features

## 2. Player Segment Analysis

### 2.1 Player Demographics

- **Primary Segment:** Individual players on gomafia.pro
- **Size:** Largest user segment (estimated majority of user base)
- **Engagement Level:** Daily active users (target metric)
- **Technical Sophistication:** Mixed (simple to advanced analytics needs)

### 2.2 Core Player Needs

#### Performance Tracking [HIGH PRIORITY]

**What Players Want:**

- **Role-based Performance Metrics:**
  - Don performance statistics
  - Mafia performance statistics
  - Sheriff performance statistics
  - Citizen performance statistics
- **ELO Rating System:**
  - Current ELO rating
  - ELO trends over time
  - Historical ELO progression
- **Win Rate Analysis:**
  - Overall win rate
  - Win rate by role
  - Win rate trends
  - Win rate comparisons

**Evidence from Brainstorming:**

- Identified as core value proposition
- Timeline graphs showing ALL data
- Historical performance trends

#### Historical Data Access [HIGH PRIORITY]

**What Players Want:**

- Complete game history
- Timeline visualization of all games
- Filterable by date, role, outcome
- Export capabilities for personal records

**Evidence from Brainstorming:**

- "Timeline Graphs (ALL data)" explicitly mentioned
- Historical performance tracking identified as key feature

#### Improvement Insights [MEDIUM PRIORITY]

**What Players Want:**

- Personalized recommendations
- Strategy suggestions based on performance patterns
- Comparison with top players
- Weakness identification

**Evidence from Brainstorming:**

- "AI-Powered Analytics Assistant" concept
- "Personalized Insights" mentioned
- "Performance Forecasting" identified

#### Social Features [LOW-MEDIUM PRIORITY]

**What Players Want:**

- Compare performance with friends
- Share achievements
- Follow other players
- Leaderboards

**Evidence from Brainstorming:**

- "Social Sharing (VK, Telegram)" identified
- "Follow Players/Clubs" concept
- "Performance Showcase" feature

### 2.3 Player Willingness to Pay

**Free Tier Expectations:**

- Basic player statistics
- Limited historical data (e.g., last 50 games)
- Standard visualizations
- Basic role performance

**Premium Tier ($5-8/month) - What Would Drive Conversion:**

1. **Full Historical Data Access** [HIGH VALUE]
   - Complete game history
   - Unlimited timeline graphs
   - Export capabilities

2. **Advanced Analytics** [MEDIUM VALUE]
   - Performance predictions
   - AI-generated insights
   - Comparison tools
   - Advanced filtering

3. **Social Features** [LOW-MEDIUM VALUE]
   - Share analytics
   - Compare with friends
   - Achievement showcase

**Conversion Drivers:**

- Players who play daily/weekly
- Competitive players seeking improvement
- Players tracking long-term progress

**Estimated Conversion Rate:** 2-5% (industry standard for freemium)

## 3. Judge Segment Analysis

### 3.1 Judge Demographics

- **Primary Segment:** Tournament judges on gomafia.pro
- **Size:** Smaller segment but HIGH VALUE
- **Engagement Level:** Regular (tournament-based)
- **Technical Sophistication:** Moderate to high (professional use case)

### 3.2 Core Judge Needs [KILLER FEATURE]

#### Tournament History Tracking [CRITICAL]

**What Judges Want:**

- Complete tournament history
- Games judged per month statistics
- Tournament outcomes and results
- Table assignments tracking

**Evidence from Brainstorming:**

- Explicitly identified as "KILLER FEATURE"
- "Cannot be removed" - critical to value proposition
- "Tournament History" listed as priority

#### Earnings Tracking [HIGH PRIORITY]

**What Judges Want:**

- Total earnings over time
- Earnings per tournament
- Earnings per month/year
- Earnings trends and projections

**Evidence from Brainstorming:**

- "Earnings Tracking" identified as key feature
- Part of judge analytics dashboard priority

#### Performance Metrics [HIGH PRIORITY]

**What Judges Want:**

- Average extra points analysis
- Judge performance metrics
- Consistency metrics
- Judge impact analysis

**Evidence from Brainstorming:**

- "Judge Performance Metrics" identified
- "Average Extra Points Analysis" mentioned
- "Judge Impact Analysis" concept

#### Reputation System [MEDIUM PRIORITY]

**What Judges Want:**

- Judge badges
- Reputation scores
- Consistency tracking
- Recognition system

**Evidence from Brainstorming:**

- "Judge Reputation Ecosystem" concept
- Gamification elements for judges

### 3.3 Judge Willingness to Pay

**Premium Tier ($8-12/month) - High Willingness to Pay:**

**Why Judges Would Pay:**

1. **Professional Use Case:** Judges use analytics for work/earnings
2. **Unique Value:** No other platform offers judge-specific analytics
3. **Earnings Tracking:** Direct ROI on subscription cost
4. **Tournament Management:** Tools that help their professional activities

**Key Features That Justify Premium:**

- Complete tournament history
- Earnings tracking and trends
- Judge performance analytics
- Export capabilities for records
- Priority data updates

**Estimated Conversion Rate:** 10-15% (higher than players due to professional use case)

**Revenue Potential:** Higher ARPU despite smaller user base
